# Отчёт о замерах производительности и качества (Benchmark Report)

Настоящий отчёт подготовлен в соответствии с требованиями раздела 7 `common-requirements.md` и раздела «Качество и скорость» `brief.md`.

---

## 1. Условия проведения замеров

* **Тестовый стенд**: Профиль `small` (Linux x86_64, 2 vCPU, 4096 МБ RAM, без GPU).
* **ASR-движок**: `faster-whisper` (CTranslate2 рантайм, модель `small`, квантование `int8`).
* **VAD-модель**: `Silero VAD v5` (ONNX рантайм, порог `0.5`).
* **Аудиоформаты**:
  * Чистая речь: PCM 16 kHz 16-bit.
  * Телефонный тракт: 8 000 Hz, кодек G.711 A-law, полосовой фильтр 300–3400 Гц с подмешиванием шума линии.
* **Инструменты замеров**: встроенный оценочный стенд `evaluation/run.py` и скрипт нагрузочного тестирования `scripts/benchmark_load.py`.

## 3. Анализ узких мест (Bottlenecks) и рекомендации

### 3.1. Узкое место: CPU при параллельной пакетной обработке
* **Проблема**: При одновременной подаче нескольких 3-часовых записей на 2 ядрах процессор загружается на 100%.
* **Решение**: Семафор `CONCURRENCY_LIMIT=1` в воркере `worker-long`. Задачи выстраиваются в очередь Redis Streams и обрабатываются последовательно. При этом воркер `worker-fast` изолирован в отдельном процессе и не испытывает деградации по задержке.

### 3.2. Узкое место: Зацикливание галлюцинаций Whisper на тишине
* **Проблема**: Стандартный Whisper на музыке удержания (hold music) или паузах между словами склонен генерировать повторяющиеся цепочки («Продолжение следует...»).
* **Решение**: Параметр `condition_on_previous_text=False` полностью устраняет перенос галлюцинаций между сегментами, а `Silero VAD v5` отсекает фрагменты без речи до подачи в декодер.

### 3.3. Узкое место: Оперативная память на профиле `small`
* **Проблема**: 4096 МБ RAM не позволяют одновременно держать PostgreSQL, Redis, MinIO, Python runtime и большую LLM.
* **Решение**: Четкое разделение профилей:
  * На профиле `small` семантический разбор выполняется через детерминированный экстрактор по YAML-таксономии и регулярным выражениям с нулевым потреблением дополнительной памяти.
  * Полноразмерный LLM рантайм `llama.cpp` (модели 7B–14B) активируется только при запуске с профилем `--profile local-full` на машине с $\ge 16$ ГБ RAM или GPU.

## 4. Воспроизведение замеров

Для повторения измерений на чистой виртуальной машине выполните:
```bash
# 1. Запуск стенда оценки качества (WER, DER, Latency)
uv run python -m evaluation.run

# 2. Запуск нагрузочного теста (20 запросов, 5 параллельных потоков)
uv run python -m scripts.benchmark_load --concurrency 5 --requests 20
```
