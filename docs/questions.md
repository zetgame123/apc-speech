# Открытые вопросы и статус согласования

## Открытые вопросы (2026-10-11)

0. **MinIO под AGPLv3 в закрытом продукте (требует решения)**: образ MinIO
   (minio/minio, у нас `elestio/minio` — тот же апстрим) распространяется под
   GNU AGPLv3 с 2021 года (до этого Apache 2.0). Сетевая клаузула AGPL (разд. 13)
   при доступе по сети к модифицированной версии требует раскрытия исходников.
   Варианты: (а) коммерческая лицензия MinIO (AIStor); (б) замена S3-хранилища
   (SeaweedFS, Garage, Ceph RGW — лицензии проверить отдельно);
   (в) зафиксировать «немодифицированный образ, только внутри контура» с
   принятием остаточного риска. Без решения — СТОП для поставки (ADR-012).

1. **T-one без пунктуации и регистра**: экспериментальный greedy-декодер T-one
   (алфавит CTC — 33 строчные буквы + пробел, `tone/decoder.py: LABELS`) возвращает
   текст без пунктуации и заглавных букв. Если T-one будет выбран движком быстрого
   пути, допустим ли сырой текст (пунктуацию добавит только ITN-нормалайзер чисел/
   терминов) или требуется отдельный модуль восстановления пунктуации/регистра?
   Пока пунктуация не добавляется (зафиксировано, не додумано).

2. **Лицензия весов SlovNet/Navec (Natasha NER)**: на код — MIT
   (natasha/slovnet, natasha/navec, LICENSE проверены), а на сами веса
   (`slovnet_ner_news_v1.tar`, `navec_news_v1_*.tar` с Yandex Cloud) явного
   гранта нет — только контекст MIT-репозитория. Дополнительно: navec-модель
   `hudlit` обучена на корпусе Либрусека (provenance данных). Просьба:
   подтвердить допустимость весов в закрытом продукте или запросить авторов
   (issues natasha/slovnet). До ответа — допущение «по месту публикации» (ADR-012).

3. **Provenance CAM++ ONNX**: веса берутся с неофициальных зеркал
   (welcomyou/hb123xyz, оба маркированы apache-2.0; официальный HF-миррор
   funasr/campplus — тоже apache-2.0; страница ModelScope напрямую не прочитана).
   Желательно сверить эмбеддинги с выходом оригинального `.pt` с ModelScope
   либо перейти на официальный источник.

## Согласованные решения с заказчиком (2026-09-28)

1. **Обработка автоответчиков и IVR**:
   * *Вопрос*: Как обрабатывать звонки, в которых на первых секундах обнаружен автоответчик / голосовая почта?
   * *Решение*: Прерывать тяжелый LLM-разбор, помечать звонок флагом `is_answering_machine=true` и сохранять только базовый транскрипт. Это существенно экономит ресурсы процессора.

2. **Срок хранения по умолчанию (Retention Policy)**:
   * *Вопрос*: Какой срок хранения установить по умолчанию для аудиозаписей и транскриптов?
   * *Решение*: 14 дней для аудио в MinIO и 365 дней для текстовых транскриптов в PostgreSQL с поддержкой раздельного и полного каскадного удаления (`DELETE /v1/data/delete`).

3. **Формат запуска этапов разработки**:
   * *Вопрос*: С какого этапа начинаем реализацию?
   * *Решение*: Фиксация проектных M0-артефактов (`docs/`, `openapi.yaml`, конфиги, схемы) и немедленный переход к сквозному вертикальному срезу M1 (`audio upload -> job -> ASR -> transcript`).

## Открытые вопросы для дальнейших релизов

1. **Процессор целевого сервера (AVX2)**: поддерживает ли CPU продакшн/приёмочного сервера
   флаг AVX2 (`grep -o avx2 /proc/cpuinfo`)? Без AVX2 SLA голосового поиска (10 с → 2,5 с)
   и RTF часовой записи недостижимы (замеры B1: инференс 3 с аудио — 43 с при 1 потоке,
   7 с при 4 потоках на AVX1-VM; см. `docs/known-issues.md` п.5–6). Сервис сообщает флаг
   в `GET /health` → `details.avx2`.
2. **Размер батча в `/v1/texts/analyze`**:
   * Ограничение размера пачки текстов в одном синхронном запросе (рекомендуется: до 500 текстов синхронно, свыше 500 — через создание фонового задания).
2. **АТС интеграция**:
   * Требуется ли поддержка вебхуков специфичных виртуальных АТС (MANGO OFFICE, UIS, МегаФон) напрямую или только через общий API платформы?

## Лицензии — к юристу/заказчику (аудит A4, 2026-10-10)

Контекст: по `AGENTS.md` п.5 новая модель/библиотека подключается только после записи
лицензии в `docs/decisions.md`; записи там нет, `README.md:991` («все MIT/Apache-2.0»)
проверкой не подтверждено. Ниже — то, что требует решения до приёмки.

1. **`campplus.onnx`** (диаризация, community-конверсия 3D-Speaker): подтвердить, что
   исходная лицензия (Apache-2.0/MIT) покрывает используемый ONNX-файл и его источник
   (`welcomyou/...` / `hb123xyz/...` в `scripts/download_models.py:20-24`).
2. **Образ MinIO (AGPLv3)** (дефолт `docker-compose.yml` — `elestio/minio:latest@sha256:2534…`,
   digest зафиксирован в B2): приемлем ли AGPL-компонент как немодифицированный образ
   внутри контура? Фиксируем «без модификаций, сеть только внутри» или заменяем
   (например, SeaweedFS/Garage)?
3. **Образ Redis** — вопрос снят выбором версии: зафиксирован `redis:7.2-alpine` (B2),
   ветка 7.2 распространяется под BSD-3-Clause (проверено по `COPYING` тега 7.2 в
   апстриме 2026-10-11; RSALv2/SSPLv1 начались только с 7.4). При обновлении Redis
   ≥7.4 вопрос лицензий переоткрыть.
4. **Qwen2.5-7B-Instruct GGUF** (только `local-full`): вопрос снят — действующие
   условия Apache 2.0 (карточки `Qwen/Qwen2.5-7B-Instruct(-GGUF)`, LICENSE в
   репозитории; Tongyi Qianwen License superseded), см. ADR-012.
5. **Словари/веса Natasha (navec/slovnet)**: подтвердить лицензии морфологических
   ресурсов отдельно от MIT-кода библиотеки (см. п.2 выше — открыто).

Закрыто: `bond005/whisper-podlodka-turbo-ct2` — Apache 2.0 (карточка HF + API-тег
`license:apache-2.0`, проверено 2026-10-11), записано в ADR-010. Redis — см. п.3.

4. **KenLM (LGPL-2.1) для hotword-LM в T-one**: библиотека KenLM
   распространяется под LGPL-2.1 (проверено по `kpu/kenlm` LICENSE 2026-10-12).
   Допустимо ли подключение как немодифицированной разделяемой библиотеки
   (аналогично `soxr` в ADR-012) ради KenLM-декодера с кастомным словарём
   терминов, или держать запрет (тогда только собственный beam без LM)?

5. **Окно голосового запроса при доле 503 > 1% (ждет решения, не реализовано)**:
   замер 2026-10-12 (3,0 ГГц, окно 2,4 с): стоковый дефолт (TONE_THREADS unset) —
   800/800 → 503; с TONE_THREADS=1 — 0/800, но p95 2,39 с при окне 2,4 с.
   Варианты: (а) окно от длительности аудио; (б) поздний ответ до жёсткого
   предела; (в) TONE_THREADS=1 по умолчанию. Последствия для контракта —
   в `reports/voice_sla_window_2026-10-12_3ghz.json`. Без решения не менять.

6. **Qwen2.5-3B-Instruct-GGUF под qwen-research**: карточка HF помечена
   `License: qwen-research`, а не Apache 2.0 (в отличие от 7B). Что разрешает
   эта лицензия для закрытого продукта — не установлено. До ответа 3B-модель
   не скачивать и не использовать.
