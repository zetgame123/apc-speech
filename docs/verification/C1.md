## 2. Стерео с раздельными каналами

- Перекрывающееся стерео (речь в обоих каналах одновременно): метрики
  `overlap=0.627` → ветка `stereo_channels_not_isolated_using_mono_diarization`
  (моно-диаризация всего микса). Решение осознанное, залогировано.
- Неперекрывающееся стерео (L: клиент 0–5,3 с, тишина; R: тишина, менеджер с 5,5 с,
  сгенерировано numpy из `sample_dialogue_01_clean.wav`): задание `67d44f8f-…` →
  `succeeded`, 2 сегмента строго по половинам каналов с разными ролями
  (`SPEAKER_0/manager`, `SPEAKER_1/client` — по `channel_mapping`
  `channel_manager=0, channel_client=1`; дефолт ch0=manager/ch1=client,
  `app/diarization/roles.py:94-106`).

## 4. Приём по ссылке и из S3

- `POST /v1/jobs/by-url`, внутренний адрес → `ssrf_protection_triggered`
  (`blocked_ip`, проверено на `169.254.169.254`).
- Публичный URL (Wikimedia Example.ogg): задание принято, скачивание упёрлось
  в `403 Forbidden` remote-стороны → задание `failed` с `audio_download_error`,
  сервис не упал (корректная обработка).
- Публичный URL (piano2.wav): задание `a16601c2-…` → `succeeded` (скачивание,
  транскрибация). Транскрипт пустой (`full_text=""`, 0 сегментов) — музыка
  корректно отброшена VAD (задел под C2).
- `POST /v1/jobs/by-s3` (объект залит в MinIO `raw-audio` через boto3 изнутри
  контейнера api): задание `f0177a5d-…` → `succeeded`, транскрипт идентичен upload.
