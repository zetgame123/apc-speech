# C2. Распознавание русской речи — живая проверка (2026-10-11)

Стенд `apc_small`, namespace `c2_verify`, синтетика. Код: `app/asr/engine.py`
(faster-whisper, VAD, `initial_prompt`/`hotwords`), `app/asr/normalizer.py` (ITN),
`app/asr/vad.py`; тесты `tests/test_normalizer.py`, `tests/test_preprocessor.py`.

## 1. Пунктуация, регистр, таймкоды слов, уверенность

Транскрипт C1/C2 (`/v1/calls/{id}/transcript`): «Здравствуйте! Подскажите стоимость
суперсайта на Ленинградке. …» — пунктуация и регистр на месте; каждый сегмент:
`start/end`, `confidence`, `words[]` с пословными `start/end/confidence`
(пример: `{"word":" Здравствуйте!","start":0.0,"end":0.8,"confidence":0.507}`).

## 2. VAD: тишина, музыка, бип не превращаются в текст

| вход | результат |
|---|---|
| тишина 5 с (`silence5.wav`) | `succeeded`, 0 сегментов, `full_text=""` |
| бип 1400 Гц 1,5 с + тишина (`beep_machine.wav`, имитация автоответчика) | `succeeded`, 0 сегментов |
| музыка piano2.wav по by-url (C1) | `succeeded`, 0 сегментов |

## 3. Детекция языка

Задание `hint_no` с `language=auto` → корректный русский транскрипт.
Код: `resolved_lang = None if language == "auto"` + `info.language` faster-whisper.

## 4. Подсказки терминов

- Конфиг `config/vocabulary_hints.yaml` грузится движком всегда
  (`AsrEngine.vocabulary_prompt`, `app/asr/engine.py:44-77`).
- Параметр клиента `vocabulary_hints` (Form): upload → payload
  (`app/api/jobs.py:308`) → `initial_prompt`+`hotwords` в обоих ветках воркера
  (стерео `long_audio_processor.py:177-178,199-200`, моно `:246-247`) и в
  голосовом пути (`app/api/voice.py`, `app/workers/fast_voice_search.py`).
- Живая дельта на OOV «зорбощит» (без/с `vocabulary_hints=зорбощит`):
  оба раза «зарбощит» — неубедительно: gTTS с редукцией, вероятно, так и
  произнёс (транскрипт соответствует аудио). Дефекта проводки нет;
  словарные слова («медиафасад») узнаются стабильно в обоих режимах.

## 5. Нормализация чисел со склонениями

Живой TTS-тест (`numbers.wav`, 18,7 с): «после пятнадцати секунд гудка» →
«после 15 секунд гудка»; «тариф две тысячи рублей» → «2000 рублей»;
«пятого октября» → «5 октября»; телефон → маскирован (см. C7).
Юниты: `test_billboard_dimensions_normalization` («три на шесть»→«3×6»),
`test_time_normalization`, `test_currency_normalization`, краевые тесты.

## Расхождения с ТЗ

Нет. Живая дельта подсказок на OOV неубедительна по причине выше
(не дефект кода) — зафиксировано честно.
