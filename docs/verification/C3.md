# C3. Говорящие — живая проверка (2026-10-11)

Код: `app/workers/long_audio_processor.py` (ветка стерео/моно),
`app/diarization/mono_diarizer.py`, `app/diarization/roles.py`;
тесты `tests/test_diarization.py`, `tests/test_roles.py`.

## 1. Стерео по каналам

Неперекрывающееся стерео (L: клиент 0–5,3 с; R: менеджер с 5,5 с):
2 сегмента строго по половинам, `SPEAKER_0`/`SPEAKER_1`.
Роли назначены по declared `channel_mapping` (`channel_manager=0` →
содержимое L помечено `manager`): дефолт `{"channel_0": "manager",
"channel_1": "client"}` (`roles.py:94-106`). Маппинг соблюдается, а не захардкожен.
Перекрывающееся стерео → осознанный fallback в моно-диаризацию
(`stereo_channels_not_isolated_using_mono_diarization`, overlap=0.627).
