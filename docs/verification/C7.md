# C7. Персональные данные — живая проверка (2026-10-11)

Код: `app/pii/masker.py`, `app/api/admin.py::delete_data`,
`app/llm/external_adapter.py`, `scripts/retention_loop.py`;
тесты `tests/test_pii_masker.py`, `tests/test_admin_api.py`.

## 1. Маскирование

- Живьём: произнесённый телефон в расшифровке маскирован —
  «по телефону +[ТЕЛЕФОН_1]» (`/v1/calls/.../transcript?masked=true`).
- E-mail/карты/документы: юниты `tests/test_pii_masker.py` (паттерны + отсутствие
  утечек в логах через guard `no_pii_in_logs`). Живой TTS-тест не делался осознанно:
  TTS произносит цифры словами, что не соответствует проверяемым паттернам —
  зафиксировано, не дефект.

## 2. Удаление одной ручкой (namespace `c7_verify`)

`DELETE /v1/data/delete` (scope admin):
- `?call_id=` → `{"deleted_calls":1,…}`;
- `?manager_id=mgr_del_part` (участник) → `{"deleted_calls":1,…}`;
- `?date_from=…%2B00:00&date_to=…` (период) → сначала **500**
  (`AsyncAdapt_asyncpg_dbapi.Error: can't subtract offset-naive and
  offset-aware datetimes` — aware-параметр vs naive `created_at`).
  **Дефект исправлен**: normalize tz в `delete_data` (как в `list_calls`),
  регрессионный тест `test_delete_data_by_period_with_tz_aware_dates`,
  живой ретест → `{"deleted_calls":1,…}`, namespace пуст.

## 3. Раздельные сроки хранения

`RETENTION_AUDIO_DAYS=14` / `RETENTION_TEXT_DAYS=365` (`app/core/config.py`).
Живая проверка истечения сроков невозможна (дни/недели) — не проверено, причина:
время; логика в `scripts/retention_loop.py`.

## 4. Внешний провайдер выключен

`LLM_EXTERNAL_PROVIDER_ENABLED=false` (env воркера, проверено `docker exec`).
Код: адаптер принимает только маскированный текст + `assert_no_leaked_pii`
(`app/llm/external_adapter.py:24-52`) — немаскированный текст провайдеру
не уходит по построению.
