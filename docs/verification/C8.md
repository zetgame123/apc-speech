# C8. Хранение и поиск — живая проверка (2026-10-11)

Код: `app/api/calls.py` (transcript `format=json/text/srt/vtt`, список с
`q/manager_id/inquiry_type/date_*`, курсор), `app/core/security.py`
(`verify_namespace` → 403); тесты `tests/test_security.py`,
`tests/test_api_contract.py`.

## Проверено живьём

- SRT: нумерация, `00:00:00,000 --> 00:00:00,800`, `[client] текст`. VTT: заголовок
  `WEBVTT`, `00:00:00.000 --> 00:00:00.800`, `<v client>`. (Замечание: кириллицу
  в query надо URL-кодировать — сырой UTF-8 в строке запроса роняет uvicorn
  `Invalid HTTP request received`; клиентская обязанность, не дефект.)
- Полнотекст: `q=суперсайт` → попадания; `q=несуществующийтермин` → `[]`.
  Фильтры: `inquiry_type=other` → 2/2; пагинация курсором (`next_cursor`).
- Изоляция namespace (скоуп-токены `hash:read:ns` через `API_TOKENS_HASHED`,
  оверрайд снят после проверки): токен A (c1_verify) свой ns → 200, чужой →
  `403 forbidden_namespace` («Токен привязан к namespace…»); токен B зеркально.
  Клиенты не видят друг друга.
